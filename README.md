# FrontendDealDash - Frontend Documentation

Repository: [https://github.com/RendhiAdhiP/FrontendDealDash](https://github.com/RendhiAdhiP/FrontendDealDash)

## 📌 Teknologi
- React JS (Vite)
- Tailwind CSS
- ShadCN UI
- React Router DOM
- Axios
- React Context / React Query

## 📋 Fitur Tampilan

### 🔐 Login Page
- Form email dan password
- Menyimpan sesi user setelah login

### 📊 Dashboard
- Statistik dan informasi ringkas

### 👤 Manajemen User
- List user
- Tambah, edit, hapus, dan lihat detail

### 🏙️ Manajemen Kota
- List kota
- Tambah dan edit

### 📦 Manajemen Produk
- List produk
- Tambah, edit, lihat detail produk

### 🧮 Stok Produk
- Form penambahan stok
- Riwayat penambahan stok produk

### 🧾 Role View
- Menampilkan daftar role dan aksesnya

## 🧩 Struktur Halaman

- `/login`
- `/dashboard`
- `/user`
- `/city`
- `/product`
- `/stock`
- `/role`

## ⚙️ Cara Install Lokal

```bash
# 1. Clone repository
git clone https://github.com/RendhiAdhiP/FrontendDealDash.git
cd FrontendDealDash

# 2. Install dependency
npm install

# 3. Jalankan server
npm run dev
